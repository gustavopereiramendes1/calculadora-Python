# 🖩 Calculadora com Tkinter

Uma calculadora simples desenvolvida em Python utilizando a biblioteca Tkinter para a interface gráfica.

## 🚀 Funcionalidades
- Operações básicas: **adição (+), subtração (-), multiplicação (×) e divisão (÷)**
- Interface gráfica amigável e intuitiva
- Botão de limpar a tela
- Exibição dinâmica dos cálculos em um visor

## 🛠️ Tecnologias Utilizadas
- **Python** 🐍
- **Tkinter** 🎨 (para a interface gráfica)

## 📌 Como Executar o Projeto
1. **Clone este repositório**:  
   ```sh
   git clone https://github.com/seu-usuario/calculadora-tkinter.git
   
2. Acesse a pasta do projeto:
   ```sh
   cd calculadora-tkinter

3. Execute o script Python:
   ```sh
   python calculadora.py
4. Ou execute o .exe
